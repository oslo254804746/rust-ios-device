**验收条件：**

  仅驻内存，扫描与脱敏完成后才能打印或落盘，不保留绕过捕获器的收尾路径。
- 使用合成秘密标记验证 stdout、stderr、失败、超时和清理分支；泄漏检测结果与
  脱敏副本分开记录，不能用“脱敏文件零命中”证明原始输出没有泄漏。
- 宿主身份文件生成于证据目录之外的本轮专用临时目录。交付前按允许文件清单审计，
  清理本轮产生的私钥与秘密映射，并核查没有本轮进程残留。

- 保留事故事实：删除本地文件不能撤回已经进入终端转录的内容；精确 UDID 零命中

## FUP-04：T-05 Windows 输出路径单轮补测

**启动条件：** FUP-03 通过；设备所有者预先放置一个小型合成文件，并明确授权读取
该精确设备路径；已知 fixture 内容、大小和 SHA-256；本机使用独立临时输出目录。
本文不授予设备上传、读取用户媒体或修改设备状态的权限。条件未满足时保持 NOT_RUN。

**目标与范围：** 使用普通 `com.apple.afc` 的 `file pull` 验证读取与 Windows 本地
落盘链路。只读该 fixture，不扩大到目录批量下载，不以 House Arrest 等服务替代。

| 子用例 | 验收条件 |
| --- | --- |
| 新建文件 | 成功退出；字节数、SHA-256 与已知 fixture 一致 |
| 目标已存在，不加 `--force` | 明确失败；原有合成目标内容不变 |
| `--force` 覆盖 | 成功退出；内容完整替换且 hash 一致 |
| Unicode 输出路径 | 写入预期位置；内容与普通路径一致 |
| 普通长路径 | 完整绝对路径超过 260 个 UTF-16 代码单元；记录长度，验证落盘内容 |
| 显式 verbatim 路径 | 验证 `\\?\` 形式；记录实际参数及目标路径，不能只统计退出码 |
| 只读文件、目录目标等失败场景 | 使用 `--force` 验证替换失败；旧文件 hash 或目录内合成 marker 不变；明确失败且临时文件清理正确，不能用未加 `--force` 的前置拒绝替代 |
| 失败后正常下载 | 新一次合法调用成功，内容校验通过，无本轮残留文件或进程 |
| 真实 UNC 共享 | 另需明确授权的共享；无共享则该子项保持 NOT_RUN |

**证据与判定边界：**

- F2 长路径兼容与本地输出链路可由本轮补测覆盖；F1 内嵌 NUL 无法通过 CLI 参数传入，
  继续标为 host-only，不能宣称 T-05 关闭了其真机覆盖缺口。
- 严格区分设备路径和宿主输出路径，记录实际参数；Git Bash 调用须禁用 MSYS 路径转换。
- 每项记录受测提交、二进制校验值、脱敏参数、耗时、退出码、文件大小/hash、目标与
  临时文件状态；只记录合成内容，不导出配对记录或设备秘密。
- 出现异常时，用 pmd3/go-ios 对同一授权 fixture 做等价只读对照；分别判断 AFC 读取
  与宿主落盘问题。上游工具无等价能力或 Windows 路径语义不同时明确记录，不能硬判 parity。
- 继承原任务书上限：普通命令 60 秒、特殊建连 90 秒；每方初次执行后最多重试 2 次，
  单项阻塞调查最多 15 分钟。重复同一失败且无新证据时提前停止；权限不足不重试绕过。

**交付与停止条件：** 一份独立补测报告及仓库外脱敏证据。缺条件项逐项保留 NOT_RUN；
矩阵结束或触达上限即收尾。发现疑似产品缺陷时提交最小复现与归因证据，另拆修复任务，
