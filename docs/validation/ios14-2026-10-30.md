## 本轮修复

- 经典 symbols 批量下载此前在列目录后复用同一连接，iOS 14 关闭连接。改为每个命令单独连接；单文件与修复后全量真机复测。CLI symbols 测试 4 项通过。
- SDK 检查路径此前要求 `EnableServiceSSL` 必须存在。该手机对明文安装代理和 AFC 服务的实际 StartService 应答省略该字段，而 syslog 应答明确为 true；改为仅在省略时采用明文，非布尔值仍拒绝。checked-session 测试 18 项通过；C/Python 同步及异步真机复测成功。
- 此手机存在 JSON 头加旧式文本正文的 `.ips`；原解析器返回 InvalidData。按实际文本头识别该格式并保留 JSON 头与原文；真实样本重测成功且提取到进程和异常字段。启用 crashreport feature 的 29 项测试通过。
- Doctor 曾把设备明确返回的 `UnknownCommand` 当作 Developer Mode 和个性化镜像检查失败。针对这两项将此应答标为未知／不支持，同时保留原始错误类别；其他设备错误仍为失败。32 项相关测试通过，真机复测两项均为 unknown/unsupported；DDI 未挂载时开发服务仍报不可用，故命令整体仍为 exit 1。
- CLI 和 SDK 构建完成，`cargo fmt --all -- --check` 与 `git diff --check` 通过。CLI 全量并发测试 1,999 通过、4 失败、22 忽略；四项单独串行重跑均通过，不能据此断言并发失败原因。全量串行复核 2,003 通过、22 忽略（上述全量测试发生在 Doctor 局部修复之前）；C 绑定 38 项通过，Python 绑定隔离运行时 22 项通过。Python 测试初次因 DLL 搜索失败未运行，提供隔离 DLL 和运行时目录后通过。继承的 48 个源码基线文件和四个交接保护文件未改变；本轮新增改动仅为上述修复及对应测试。源码与二进制哈希保存在私有目录。

## 失败、限制与待验收

- **设备端 Unback：** Rust 在隔离副本自然 exit 1，`UnexpectedEof`；参考实现对另一份新副本也发生连接终止。此为两种客户端同现象，尚不能证明根因。单文件设备端 Extract 已独立通过。
- **本地 Unback：** Windows 路径返回失败；私有诊断工具报告符号链接展开在当前平台不支持。它与设备端 EOF 是不同观察，不能互相解释。
- **file-relay：** Rust 和参考实现在服务连接阶段均失败；无归档，不能验收全量输出。
- **FPS：** `--count 2` 两次及 `--count 3` 一次均在输出指定样本后 exit 1，错误类别 protocol；`--count 1` exit 0。独立探针一次完成并成功发送 stop，后续一次提示无法设置当前录制会话；无法据此确认根因或远端清理。源码测试明确指出完成时取消部分 DTX 帧不能保证后续 stop 成功，这是可能关联的生命周期边界，不作为已证实根因。为恢复现场再次卸载 DDI 并重启。
- **混合 crash 目录：** 修复后逐文件解析 282 个 `.ips`，257 个成功，25 个仍失败；这些失败样本含额外 JSON 头及文本正文，头和正文事件标识未对应，暂不猜测其语义。对完整导出目录执行 parse-latest 失败；筛选出一份真实旧格式报告后 parse-latest 成功。
- **debugserver：** qSupported 查询 exit 1、protocol，尚缺对应参考对照。
- **崩溃监听 / 通知 / 伴侣 / 蓝牙：** 当前无新 crash、通知或配对伴侣事件；蓝牙采集未得到有效 HCI 包，均缺正向事件素材。WebInspector 标签列表为空，无法验收页面操作。
- **其他限制：** font-size 查询 exit 1，尚未确认设备是否提供对应键。Doctor 的 Developer Mode 和个性化检查在该设备返回 `UnknownCommand`，已修复分类并完成真机复测；开发服务检查失败发生在 DDI 未挂载时，不能单独归为缺陷。IP 从抓包发现地址的五秒尝试超时，未取得地址。部分接口需要受控测试 app、Web 页面、伴侣硬件、事件或人工解锁。CLI 和 SDK 仍有未调用项目，详见覆盖表；历史清单并非当前所有可能变体。
- **版本不适用：** CoreDevice、RSD、现代隧道、personalized DDI 和 iOS 17+ 定位分支不在该 iOS 14 设备上执行；iOS 17+ 的实测只引用前轮报告，不能把两轮结果外推至其他版本。
- **未获授权：** 真实 Restore/erase/shutdown、激活或监督变更、清密码、配置及 Wi-Fi 修改、个人应用安装启动终止、HID/剪贴板写入、系统路由与内核隧道均未执行。
